First release of **KISS Backup Client** — encrypted, deduplicated offsite backups for Linux
servers, with per-account restore for DirectAdmin. Built on restic.

### What's in it
- **Whole-server backups every hour** over SFTP (KISS storage or your own restic SFTP repo),
  encrypted on the server before upload. Daily per-database dumps, optional on-server
  mariabackup chain. Retention 24 hourly / 14 daily / 8 weekly / 12 monthly.
- **Setup wizard** (`kiss-backup-setup`) — key, connection, repository, test round-trip, schedule.
- **Console** (`kiss-console`) and **CLI** (`kiss-backup`).
- **Per-account restore (DirectAdmin)** — files, mail, DNS and databases, in place:
  - merge, or "exactly as it was" (mirror — removes planted files);
  - dry-run preview of every change; optional safety snapshot so a restore can be undone;
  - no local staging of files (no extra disk needed); only changed files are downloaded;
  - guards: account must exist, nothing outside the account is touched;
  - user/group IDs remapped **by name** if the account was re-created or the server rebuilt,
    including the IDs inside DirectAdmin's mail login files;
  - retries a dropped connection 3 times, then alerts; re-running resumes.
- **Browse a backup** — read-only `restic mount` + Midnight Commander for single-file fetches.
- **Weekly integrity check and restore drill.**

### Tested on
CloudLinux 8.10 + DirectAdmin 1.713, restic 0.19.1. What each test does and its result:
[`tests/README.md`](https://github.com/Velocity-Host-Pty-Ltd/kiss-backup-client/blob/v0.1.0/tests/README.md).

### Known limits
- The panel account must exist before a restore — re-creating DirectAdmin accounts themselves
  is planned.
- Debian/Ubuntu supported by the installer but not yet tested. (CageFS: tested after this
  release was published — restores of caged accounts pass, see tests/README.md.)
- Resume is per file: a half-written large file is downloaded again in full.

### Install
```bash
sha256sum -c kiss-backup-client-0.1.0.tar.gz.sha256
tar xzf kiss-backup-client-0.1.0.tar.gz && cd kiss-backup-client-0.1.0
sudo packaging/install.sh && sudo kiss-backup-setup
```
